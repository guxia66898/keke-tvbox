# keke-tvbox

可可影视（KkysTv APP 同源）TVBox/影视仓 接口。

## 直接使用

影视仓/TVBox 配置地址填：

```
https://raw.githubusercontent.com/guxia66898/keke-tvbox/main/tvbox_config.json
```

## 文件

- tvbox_config.json — 单仓配置（spider 已指向本仓库 jar，带 md5 校验）
- keke_spider.jar — csp_Keke 爬虫（分类/搜索/详情/播放，直连 Web 端 kekey.cc）

## 注意

- 仅供个人技术研究，内容为成人向站点
- 域名失效时需更新 jar 内 HOST 并同步更新 md5
